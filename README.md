# Il caregiver come problema di politica pubblica

Script e figure del paper.

- `script/`: gli script R (e uno in Python per la Figura 1), numerati
- `output/`: tabelle e grafici prodotti dagli script
- `figure/`: le figure del paper, con la numerazione del testo

I microdati ISTAT (Aspetti della vita quotidiana 2022-2024, EHIS 2019) non sono nel repository: si scaricano dal sito ISTAT, microdati ad uso pubblico, e vanno in `dati/grezzi`. Gli script 08, 09 e 12 non hanno bisogno di microdati.
